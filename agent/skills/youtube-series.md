# YouTube Series & Content Calendar

Use this skill when the user wants a series, content pillars, or a multi-week plan.

## Process

1. Clarify channel niche, posting frequency, and current goals (growth, authority, product, community, etc.).
2. Define 3–5 content pillars that fit the channel.
3. Design one or more series concepts:
   - Series name + short description
   - Episode structure / format
   - 6–12 episode ideas with working titles
4. Build a simple 2–4 week content calendar:
   - Publish date or order
   - Format (long-form / Short / community post)
   - Status (idea / scripted / filmed / published)
5. Show how Shorts and long-form can support each other.

## Rules

- Keep the plan realistic for the user’s capacity.
- Prefer repeatable formats over one-off complex productions.
- Every piece should either attract new viewers or deepen relationship with existing ones.
