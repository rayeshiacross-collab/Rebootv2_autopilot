# YouTube Thumbnails & A-B Testing

Use this skill when the user asks for thumbnail ideas, text overlays, visual concepts, or A/B test variants.

## Process

1. Clarify the video topic, emotion, and target click feeling (curiosity, urgency, authority, entertainment, etc.).
2. Produce 4–6 distinct thumbnail concepts. For each include:
   - Main visual idea (what is shown)
   - Face / expression guidance if a person is on camera
   - Exact text overlay (max 3–5 words, high contrast)
   - Color / contrast notes
   - Why this concept should work
3. Rank the concepts and recommend the top 2 for A/B testing.
4. Give clear A/B test instructions:
   - What to change between variants (text, expression, background, object)
   - How long to run the test before deciding
   - What metric to watch (CTR first 24–48h is usually the key signal)

## Rules

- Text must be readable on mobile (large, few words).
- Avoid clutter. One clear focal point.
- Never promise specific CTR numbers.
- Prefer concepts that create a curiosity gap or emotional reaction without being clickbait-misleading.
