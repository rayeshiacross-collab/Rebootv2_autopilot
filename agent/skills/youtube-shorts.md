# YouTube Shorts & Short-Form

Use this skill for Shorts, vertical videos, or any content under ~60 seconds.

## Process

1. Start with a single strong idea that can be delivered in 15–45 seconds.
2. Structure:
   - 0–3s: Hook (pattern interrupt or bold claim)
   - Middle: Fast payoff or demonstration
   - End: Loop or clear CTA (follow, comment, watch next)
3. Write the full spoken script + on-screen text suggestions.
4. Suggest 5–8 Shorts titles / captions (they often double as the first line of the description).
5. Give filming notes: framing, pacing, text placement, sound design ideas.
6. If the user has a long-form video, also propose 2–3 Shorts that can be cut from it.

## Style rules

- First 1–2 seconds must stop the scroll.
- One idea per Short. No multi-part lectures.
- Spoken language, high energy or high clarity.
- On-screen text should reinforce the spoken words, not repeat everything.
- End with a reason to rewatch or engage.
