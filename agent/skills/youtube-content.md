# YouTube Content Creation

Use this skill when the user asks for scripts, titles, descriptions, hooks, CTAs, chapters, or packaging for a video.

## Workflow

1. Clarify the target audience, length, and goal of the video if not already clear.
2. Produce a tight outline first (hook → main points → payoff → CTA).
3. Write the full script or sections as requested. Mark [VISUAL] or [B-ROLL] notes where helpful.
4. Generate 5–8 title options ranked by expected click + retention potential.
5. Write a complete description with:
   - First 2 lines that work as the truncated preview
   - Timestamps / chapters if the structure supports it
   - Relevant links and hashtags at the bottom
6. Suggest 10–15 tags (mix of broad + specific).
7. Give 2–3 concrete thumbnail concept directions (text + visual idea).

## Style rules

- Open with a strong, specific hook in the first 5–10 seconds of script.
- Prefer short sentences and spoken language over formal writing.
- End with a clear next action for the viewer.
- Never invent view counts, rankings, or "guaranteed" performance claims.
