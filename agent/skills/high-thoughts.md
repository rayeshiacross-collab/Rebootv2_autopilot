# High Thoughts Channel

Retro cartoon podcast. Two hosts: **Steak** and **Potatoes**.

## Specs

| Item | Rule |
|------|------|
| Length | 12–15 minutes |
| Aspect | 16:9 |
| Title | `High Thoughts — [Topic as a question]` |
| Thumbnail | Both characters always |
| Animation | Bounce, squash/stretch, iris/starburst wipes; flat cartoon only |
| Set | Round table, two mics, ON AIR, lava lamp, retro shelf, HIGH THOUGHTS banner |
| Close-ups | Halftone: Steak blue-toned; Potatoes warm coral |

## Palette / brand

- Flat cartoon, bold black outlines, halftone on backgrounds
- No realistic rendering
- Characters always in signature outfits

## Episode flow (edit order)

Open title → host banter → topic blocks → gag inserts as needed → audience question → close

## Pipeline

Writer: `writer-high-thoughts`  
Then production → packaging as usual.

Do not mix High Thoughts voice with Rebootv2 Hope voice or course teaching voice.
