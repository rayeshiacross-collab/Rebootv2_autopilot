# Python Course (Lessons 01–17)

Use this skill for the Rebootv2 / Digi-OS Python track: fundamentals through capstone.

## Scope

- Lessons 01–12: core Python (projects, functions, conditionals, loops, lists, dicts, JSON, errors, debugging, menus, unit tests)
- Lessons 13–17: capstone (scope, Git, finish, QA, demo, portfolio handoff)
- Shared practice app: CSV → JSON lead normalizer (`track-2-capstone/src/app.py`)

## When packaging a lesson video

1. Confirm the lesson number and verified title from the course map.
2. Produce:
   - Working title options (clear, searchable, no hype)
   - Description with: 2-line hook, what the learner will build, link placeholder for lab/download, playlist note
   - Chapters if the runtime supports them
   - 8–12 tags (mix of skill + beginner terms)
   - Thumbnail concept (3–4 words max on text overlay)
3. Point to the matching practice folder (`track-1-python/lesson-XX` or `track-2-capstone/...`).
4. For capstone lessons, reference the runnable command and expected output:
   `accepted=2, rejected=1, duplicates=1` on first run of the sample leads.csv.

## Voice

- Direct teaching tone
- Short sentences
- “You will build X” language
- No psychology essay voice, no cyberpunk voice

## Boundaries

- Practice materials are topic-matched companions, not transcripts of the videos.
