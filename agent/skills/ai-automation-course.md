# AI Automation Course (Lessons 18–41)

Use this skill for the applied AI / automation track of the Rebootv2 / Digi-OS course.

## Scope

- 18–21: What AI automation is, tool stack, opportunity finding, first workflow
- 22–25: Chatbots, email/SMS, reviews/reputation
- 26–29: Content engine, long-form, social, video/audio with AI
- 30–33: Scheduling, invoicing, document processing, dashboards
- 34–37: Workflow design, Make-style multi-step, custom GPTs, tool integration
- 38–41: ROI, scaling, security/privacy/ethics, roadmap

## When packaging a lesson video

1. Confirm lesson number and verified title.
2. Produce:
   - Title options that state the outcome (e.g. “Build your first AI workflow”)
   - Description with hook, what they will design or simulate, lab/download link placeholder, sequential playlist note
   - Chapters when useful
   - Tags focused on practical automation + beginner terms
   - Thumbnail concept (outcome-focused, 3–4 words)
3. Prefer **design exercises and offline simulators** over live API calls unless the user explicitly wants provider setup.
4. Reference the offline simulator when relevant:
   `python track-3-automation/simulator.py`

## Voice

- Practical operator tone
- “Here’s the system” language
- Honest about boundaries (simulator ≠ live Make/Zapier import)
- No hype, no “replace your whole job overnight” claims

## Boundaries

- Reference JSON is teaching material, not a verified vendor import file.
- Do not invent ROI numbers.
- Security and ethics lessons must stay concrete and non-alarmist.
