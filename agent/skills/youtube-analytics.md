# YouTube Analytics & Performance Review

Use this skill when the user wants to understand how a video or the channel is performing, or what to improve next.

## Process

1. Ask for (or use browser tools to inspect) the key numbers the user can see:
   - Impressions, CTR, average view duration / retained percentage
   - Traffic sources
   - Audience retention graph shape if available
   - Top comments or common questions
2. Diagnose:
   - Packaging problem (low CTR) vs content problem (high CTR, low retention)
   - Where retention drops
   - Which traffic sources are working
3. Give prioritized recommendations:
   - Immediate packaging fixes (title / thumbnail)
   - Content structure changes for the next video
   - Ideas for follow-up videos based on what held attention
4. Suggest simple experiments (one change at a time).

## Rules

- Never invent analytics numbers. Only use what the user provides or what is visible in Studio.
- Be honest about sample size (new channels have noisy data).
- Focus on the biggest lever first (usually packaging or the first 30 seconds).
